# 순화어 점검기

보도자료 텍스트를 붙여 넣으면 기관 순화어 목록과 대조해 순화 대상 표현에 밑줄을 긋고, 권장 순화어·유형·출처·설명을 보여 주는 단일 페이지 도구입니다. 로그인, 저장, 서버, DB가 없는 정적 사이트입니다.

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm test        # 검사 로직·화면 테스트
npm run build   # dist/ 에 정적 파일 생성
```

## 순화어 목록 바꾸기

목록은 `public/sunhwa.csv` 한 파일입니다. 엑셀에서 **CSV UTF-8** 형식으로 저장해 이 파일을 덮어쓰면 코드 수정 없이 모든 사용자에게 반영됩니다.

| 대상어 | 순화어 | 유형 | 출처 | 설명 |
|---|---|---|---|---|
| 로드맵 | 이행안, 단계별 계획 | 외래어 | 국립국어원 | (선택) |

- 머리글 이름으로 열을 찾으므로 열 순서는 달라도 됩니다. 설명 열은 없어도 됩니다.
- 순화어가 여러 개면 쉼표로 구분합니다.
- 화면 아래 "순화어 목록 확인·바꾸기"에 엑셀 내용을 붙여 넣으면 그 브라우저에서만 바로 시험해 볼 수 있습니다.
- 현재 들어 있는 목록은 시연용 예시입니다.

## 일치 규칙 (`src/lib/matcher.ts`)

- 긴 표현을 먼저 찾습니다(최장 일치).
- 뒤에 붙은 조사는 두고 대상어만 표시합니다(로드맵을 → 로드맵).
- 한글 3자 이상은 띄어쓰기 차이를 허용합니다(가이드 라인).
- 2자 이하 한글은 단어 앞에서만, 영문 약어는 앞뒤가 영문이 아닐 때만 찾습니다(TF팀 O, TFT X).
- 순화어로 바꿀 때 뒤 조사(을/를, 이/가, 은/는, 과/와, 으로/로)를 맞춥니다(`src/lib/particle.ts`).

## 배포 (Vercel)

저장소를 Vercel에서 가져오면 Vite로 자동 인식됩니다. Build Command `npm run build`, Output Directory `dist` 그대로 두면 됩니다. 기관 웹서버에 올릴 때는 `dist/` 폴더 내용만 복사하면 됩니다.
